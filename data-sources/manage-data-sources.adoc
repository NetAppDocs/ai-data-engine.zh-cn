= 在 AI Data Engine 中管理数据源
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
连接数据源后，您可以监控其扫描状态，并从*已扫描系统*选项卡对其进行管理。使用这些过程可以暂停或恢复扫描、更新凭据、调整数据访问设置以及停用不再需要扫描的系统。



[[view-scan-status-and-details]]
== 查看扫描状态和详细信息

.步骤
. 从 AI Data Engine UI 中，选择 *配置*。
. 在*扫描的系统*选项卡上，找到要查看的系统。
. 选择系统行以打开详细信息视图。
+
详细信息视图显示：

+
** 当前扫描进度的状态概述
** 数据资源扫描状态细分：正在运行、已完成、已暂停和错误
** 扫描权限模式（例如，"无写入权限扫描"）
+
如果出现扫描错误，请展开错误详细信息，查看哪些卷或共享受到影响以及失败的原因。







[[pause-scanning]]
== 暂停扫描

.步骤
. 从 AI Data Engine UI 中，选择 *配置*。
. 在*扫描的系统*选项卡上，找到要暂停的系统。
. 选择系统行以打开详细信息视图。
. 选择 *暂停*。




[[resume-scanning]]
== 恢复扫描

.步骤
. 从 AI Data Engine UI 中，选择 *配置*。
. 在*已扫描系统*选项卡上，找到暂停的系统。
. 选择系统行以打开详细信息视图。
. 选择*Resume*。




[[scan-all-data-resources]]
== 扫描所有数据资源

触发对系统上所有数据资源的即时扫描。使用此选项可在重大数据更改后刷新元数据。

.步骤
. 从 AI Data Engine UI 中，选择 *配置*。
. 在*扫描的系统*选项卡上，找到要扫描的系统。
. 选择系统旁边的操作菜单。
. 选择 *Scan all volumes*（在共享和存储桶的操作菜单中有一个等效选项）。




[[retry-failed-scans]]
== 重试失败的扫描

重新排队处于失败或错误状态的数据资源。请先解决根本原因，例如凭据问题、网络错误或权限问题，然后再重试。

.步骤
. 从 AI Data Engine UI 中，选择 *配置*。
. 在*已扫描系统*选项卡上，找到扫描失败的系统。
. 选择系统旁边的操作菜单。
. 选择*重试所有扫描*。




[[edit-cifs-credentials]]
== 编辑 CIFS 凭据

更新 AI Data Engine 用于向 SMB/CIFS 共享进行身份验证的凭据。

.步骤
. 从 AI Data Engine UI 中，选择 *配置*。
. 在*已扫描系统*选项卡上，找到 SMB/CIFS 系统。
. 选择系统行以打开详细信息视图。
. 选择 *Edit CIFS credentials*。
. 输入更新后的用户名和密码，然后选择*Save*。




[[enable-or-disable-access-to-dp-volumes]]
== 启用或禁用对 DP 卷的访问

数据保护 (DP) 卷是 NetApp SnapMirror 目标卷。默认情况下，AI Data Engine 不会扫描 DP 卷。您可以按系统启用或禁用 DP 卷访问。

.步骤
. 从 AI Data Engine UI 中，选择 *配置*。
. 在*扫描的系统*选项卡上，找到系统。
. 选择系统行以打开详细信息视图。
. 选择 *Enable access to DP volumes* 或 *Disable access to DP volumes*。




[[enable-or-disable-scanning-of-specific-shares-buckets-or-volumes]]
== 启用或禁用特定共享、存储桶或卷的扫描

连接并扫描数据源后，您可以启用或禁用对单个卷或共享的扫描，而无需重新配置整个系统。使用此选项可在初始设置后优化扫描范围。例如，您可能希望排除包含无需分析数据的卷，或者添加初始扫描期间未选择或不可用的卷。

.步骤
. 从 AI Data Engine UI 中，选择 *配置*。
. 在*已扫描系统*选项卡上，找到要更新的系统。
. 在系统行中选择*查看详细信息*。
. 在数据资源列表中，找到要更改的卷、存储桶或共享。
. 使用*扫描*切换开关来启用或禁用对该资源的扫描。




[[deactivate-ai-data-engine-for-a-system]]
== 停用系统的 AI Data Engine

停用系统会停止所有扫描并将其从活动扫描覆盖范围中删除。系统配置将保留，您可以随时通过在系统行上选择 *Activate scans* 来重新激活系统。

.步骤
. 从 AI Data Engine UI 中，选择 *配置*。
. 在*已扫描系统*选项卡上，找到要停用的系统。
. 选择系统旁边的操作菜单。
. 选择*停用 AI Data Engine*。
