= 在 AI Data Engine 中监控扫描运行状况
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在对控制面板或调查结果采取行动之前，请确认基础数据是最新的。验证扫描是否正常工作，以及您的发现是否反映了最新数据。



[[verify-scan-status-and-coverage]]
== 验证扫描状态和覆盖范围

确认已连接并正在扫描所有存储系统。

.步骤
. 从 AI Data Engine UI 中，选择 *配置*。
. 在*已扫描系统*选项卡上，确认您希望看到的每个存储系统都已列出并启用扫描。
. 从系统行中选择*查看详细信息*以查看扫描进度和任何错误。有关详细信息，请参见 link:../data-sources/manage-data-sources.html["管理数据源"]。




[[validate-that-investigation-findings-reflect-current-data]]
== 验证调查结果是否反映了当前数据

如果仪表板显示大量冷数据或陈旧数据，请在根据这些数据做出决策之前确认这些数字是最新的。

* 检查导致发现的每个存储系统的上次扫描时间。最近未扫描的系统可能会低报或高报冷数据和陈旧数据。
* 确认该系统的扫描覆盖率已完成。部分扫描（已暂停、正在进行或有错误）意味着某些数据尚未评估。
* 等待下一个扫描周期，如果覆盖范围看起来不完整，则解决潜在错误。
