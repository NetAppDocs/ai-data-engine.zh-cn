= 在 AI Data Engine 中对数据执行操作
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用您定义的筛选器识别文件后，您可以直接采取行动以执行组织的数据生命周期策略。例如，存储管理员可以通过筛选找到超过一年未访问的 TB 级 VM 快照，并根据保留要求和业务策略将其批量存档到冷存储共享中，或将其删除。

.关于此任务
要执行操作，请使用复选框在"调查结果"表中选择一个或多个项目。操作工具栏将激活并显示四个选项：*删除*、*存档*、*复制*和*标记*。

您可以执行的操作取决于您分配的角色：

[cols="2,1,1"]
|===
| 操作 | AI Data Engine 管理员 | AI Data Engine 查看器 


| 标记 | 是 | 是 


| 归档 | 是 | - 


| 复制 | 是 | - 


| 删除 | 是 | - 
|===
要查看角色的完整描述，请参阅 link:../administer/manage-users-roles.html["管理用户和角色"]。



[[decide-what-to-do]]
== 决定该怎么做

根据您对数据的确定程度选择一个操作：

[cols="1,2"]
|===
| 操作 | 何时使用 


| 标记 | 在承诺存档或删除之前，您需要更多时间，或需要与其他团队协调。标记跟踪文件而不更改其位置。 


| 归档 | 数据可能仍然有价值，但不应存储在主存储中。归档会将其移至成本较低的目标位置，同时保持其可恢复性。 


| 复制 | 数据应存在于第二个位置，例如用于备份或迁移目的。复制会保留原件。 


| 删除 | 此数据不再需要，也没有保留要求。删除是永久性的，因此请仅在确定时使用。 
|===
当数据可能仍然有价值或需要进一步审核时，请选择标记、存档或复制而不是删除。仅当您确定可以安全地永久删除数据时才删除。



[[archive-files]]
== 归档文件

存档通过 NFS 或 SMB/CIFS 将文件移动到冷存储目标。您可以选择将痕迹文件保留在原始位置。

.开始之前
* 您必须具有 _AI Data Engine administrator_ 角色。


.步骤
. 在"调查"视图中，选择要存档的文件。
. 选择 *Archive*。
. 在"存档"对话框中，选择目标卷协议：
+
** *NFS*：输入 NFS 目标文件夹路径。
** *CIFS*：按格式输入 CIFS 目标文件夹路径 `\\Hostname\share_name`。提供 Active Directory 凭据：以 `domain\user`或 `user@domain`格式输入用户名，然后输入密码。


. 要在原始位置创建痕迹导航文件，请启用 *Leave breadcrumb*。
+
面包屑文件可帮助用户了解移动文件的原因。

. 选择 *Archive*。




[[copy-files]]
== 复制文件

将重复文件复制到目标卷，而不将它们从原始位置删除。

.开始之前
* 您必须具有 _AI Data Engine administrator_ 角色。


.步骤
. 在"调查"视图中，选择要复制的文件。
. 选择*复制*。
. 在"复制"对话框中，选择目标卷协议：
+
** *NFS*：输入 NFS 目标文件夹路径。
** *CIFS*：按格式输入 CIFS 目标文件夹路径 `\\Hostname\share_name`。提供 Active Directory 凭据：以 `domain\user`或 `user@domain`格式输入用户名，然后输入密码。


. 选择*复制*。




[[delete-files]]
== 删除文件

删除将从存储中永久删除文件，并且无法撤消。


CAUTION: 删除操作是永久性的，无法撤消。此操作会删除源文件，即使它们包含活动数据。

.开始之前
* 您必须具有 _AI Data Engine administrator_ 角色。


.步骤
. 在"调查"视图中，选择要删除的文件。
. 选择 *Delete*。
. 在"删除"对话框中，在确认字段中键入 *permanently delete*。
. 选择 *Delete*。


.结果
选定文件将从存储中永久删除。



[[tag-files]]
== 标记文件

标记将业务标记应用于文件以进行分类和跟踪。

.步骤
. 在调查视图中，选择要标记的文件。
. 选择*标签*。
. 输入或选择要应用的标签（例如"Archive candidate"）。
. 确认以应用标签。
