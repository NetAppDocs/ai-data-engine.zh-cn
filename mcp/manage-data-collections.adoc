= 管理用于 AI Data Engine 管理的 AI 访问的数据收集
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
集合是数据源的逻辑容器，您可以通过 AI Data Engine（AIDE）的模型上下文协议（MCP）服务器，使 AI 客户端能够搜索这些数据源。创建集合并为其启用 AI 访问，以便连接的 AI 客户端可以搜索它们。



[[before-you-begin]]
== 开始之前

* 您必须具有 _AI Data Engine administrator_ 角色。
* 您已在 AI Data Engine 中将 Microsoft Entra ID 设置为身份提供程序，其连接状态为*已连接*。请参阅 link:connect-entra-id-aide-mcp.html#set-up-an-identity-provider["设置身份提供程序"]。
* 您已创建自定义数据集合或正在使用仅包含 AI 客户端需要搜索的数据的默认集合。请参阅 <<create-a-data-collection,创建数据收集>>。




[[about-data-collections]]
== 关于数据收集

集合是一个或多个数据源的逻辑容器。AI Data Engine 提供了一个名为 *所有文件* 的默认集合，其中包括 AI Data Engine 已扫描的每个系统和卷。


CAUTION: 在授予作用域对集合的访问权限之前，请确认允许具有该作用域的所有人搜索该集合中每个文件的元数据。如果您授予作用域对 *所有文件* 的访问权限，则具有该作用域的所有人都可以搜索所有已扫描数据的元数据。

要创建集合，请参阅<<create-a-data-collection,创建数据收集>>。要稍后更改集合、身份提供程序或 MCP 服务器设置，请参阅link:maintain-mcp-setup.html["维护 MCP 设置"]。



[[create-a-data-collection]]
== 创建数据收集

创建数据集合以定义 AI 客户端可以通过 MCP 服务器搜索的数据资源。

.步骤
. 在 NetApp Console 中，转到 *AI 数据中心* > *AI Data Engine*。
. 选择*配置*，然后选择*MCP 集合*。
. 选择*创建收藏集*。
. 在 *Name* 中，输入集合的唯一名称。
. 可选：在*描述*中输入描述，以帮助您的团队了解该集合的目的。此描述最多可包含 512 个字符。
. 使用*系统*和*协议*筛选器可缩小数据资源列表。
. 选中要包含在集合中的每个数据资源旁边的复选框。
+
*扫描状态*列显示每个数据资源是*已完成*、*重新扫描*还是*错误*。无法将 S3 和结构化数据资源添加到集合中。

+
*所选行*摘要显示所选资源的数量、其扫描容量和扫描的文件数。要清除选择并重新开始，请选择*重置*。

. 选择*创建 MCP 集合*。


此时将显示一条确认消息，新集合将添加至*集合*列表，状态为*可供配置*。创建集合并不会完成其 MCP 连接配置。

*集合* 列表显示每个集合的名称、描述、卷数、扫描容量、扫描文件数、所有者和状态。对于 AI Data Engine 提供的集合，所有者为 *系统*，对于您创建的集合，所有者为 *用户*。

创建集合后，<<configure-a-collection-for-mcp,将其配置为 MCP>>。



[[configure-a-collection-for-mcp]]
== 为 MCP 配置集合

选择 MCP 集合的身份提供程序和用户范围，然后获取 AI 客户端的连接详细信息。


IMPORTANT: 在高级用户会话中，搜索不会按文件级权限进行筛选。具有集合访问权限的用户可以搜索其中的每个文件。仅包括分配到集合范围的所有用户都可以查看的文件。仅当具有该范围的每个人都被允许搜索所有扫描数据时，才授予对*所有文件*的范围访问权限。

.开始之前
* 您已创建一个 MCP 集合，或者您正在使用*所有文件*。请参阅 <<create-a-data-collection,创建数据收集>>。
* 您要使用的身份提供程序已连接到 AI Data Engine。请参阅 link:connect-entra-id-aide-mcp.html#set-up-an-identity-provider["设置身份提供程序"]。
* 与 MCP 的连接已启用。在 *MCP 集合* > *MCP 设置* 下，展开 *MCP 服务器连接* 并确认 *启用与 MCP 的连接* 已打开。默认情况下，连接处于禁用状态。请参阅 link:maintain-mcp-setup.html#enable-or-disable-the-connection-to-mcp["启用或禁用与 MCP 的连接"]。
* MCP 服务器的状态为*正在运行*。请参阅 link:maintain-mcp-setup.html#review-mcp-server-and-collection-status["查看 MCP 服务器和收集状态"]。


.步骤
. 在 NetApp Console 中，转到 *AI 数据中心* > *AI Data Engine* > *配置* > *MCP 集合*。
. 找到要配置的集合，打开其 *操作* 菜单，然后选择 *为 MCP 配置*。
. 在*选择身份提供程序*步骤中，选择一个或多个身份提供程序进行身份验证并授权对集合的访问。
+

NOTE: 如果您需要的身份提供程序未列出，请将其添加到*身份提供程序*下，然后继续。如果需要管理员访问权限，请要求管理员连接身份提供程序。

. 对于每个选定的身份提供程序，使用*要包括的用户范围*指定范围：
+
.. 要包括所有用户范围，请保持选中*所有用户范围*。
.. 要包含特定范围，请打开下拉列表，选择范围，然后选择*添加范围*。
+
`power_users` 是下拉列表中唯一的作用域，选择它将得到与*所有用户作用域*相同的结果。作用域名称必须与您在 Microsoft Entra ID 中定义的作用域匹配。



. 选择*生成 MCP 代码段*。
. 在 *生成 MCP 代码段* 步骤中，复制您的 AI 客户端所需的连接详细信息：
+
** 要直接使用端点，请选择 *MCP 服务器 URL* 旁边的复制图标。
** 要使用特定于客户端的配置代码段，请选择 Claude Desktop 的 *Claude* 选项卡或 *Code snippets* 下的 Cursor 的 *Cursor* 选项卡，然后选择复制图标。对于 Claude Code 和 OpenCode，请使用 MCP 服务器 URL。
+
在共享代码段之前，请确认主机是您的 AIDE 集群主机名，而不是集群或服务 IP 地址，并且 URL 以 `/mcp/tools`结尾，并包含此集合的 `collection_id`。作用域必须为 `\https://<host>/mcp/tools/power_users`，并且客户端 ID 必须是 Entra ID 中 AI Data Engine 应用程序的应用程序（客户端）ID。

+

NOTE: 如果出现 *MCP 主机名未设置* 警告，请选择 *MCP 设置* 以配置 AIDE 集群主机名。请参阅 link:maintain-mcp-setup.html#review-mcp-server-settings["查看 MCP 服务器设置"] 和 link:prepare-mcp-host.html["准备 MCP 主机"]。使用 HTTPS 保护 MCP 服务器需要 SSL/TLS 证书，该证书由 ingress 脚本设置。



. 可选：要更改身份提供程序或用户范围，请选择*返回*，然后再次生成代码段。
. 选择*Close*。


.结果
您拥有所选身份提供程序和用户范围的 MCP 服务器 URL 或特定于客户端的配置代码段。使用这些详细信息连接您的 AI 客户端并验证对集合的访问权限。确保您的 AI 客户端的重定向 URI 已在 Entra ID 中的 AI Data Engine 应用程序中注册。使用应用程序的应用程序（客户端）ID 作为客户端 ID。请参阅 link:configure-entra-id-mcp.html#add-redirect-uris-for-ai-clients["为您的 AI 客户端添加重定向 URI"]。


NOTE: 生成连接详细信息不会连接或验证您的 AI 客户端。link:connect-ai-clients-mcp.html["在 AI 客户端中完成这些任务"]。

在您选择身份提供程序和用户范围之前，AI 客户端无法使用集合。完成此任务后，集合的状态为*已启用*。

令牌带有已授予范围的用户可以发现并搜索该集合。没有匹配范围的用户无法发现、搜索或使用该集合。



[[disable-ai-access-for-a-collection]]
== 禁用集合的 AI 访问权限

当 AI 客户端不再需要搜索集合时，禁用该集合的 AI 访问权限。当您为 MCP 配置集合时，AI 访问将自动启用。

.步骤
. 在 NetApp Console 中，转到 *AI 数据中心* > *AI Data Engine* > *配置* > *MCP 集合*。
. 打开集合的*操作*菜单并选择*禁用*。


应用更改后，使用禁用集合的 AI 客户端将失去对其的访问权限。您的身份提供程序和用户范围选择将保留。禁用与 MCP 的连接时，AI 客户端也无法访问任何集合。要一次阻止对所有集合的请求，请参阅 link:maintain-mcp-setup.html#enable-or-disable-the-connection-to-mcp["启用或禁用与 MCP 的连接"]。
