= AI Data Engine 快速入门
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
通过部署服务、连接存储系统并开始您的第一次调查，让 AI Data Engine 启动并运行。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一个"] 查看要求
[role="quick-margin-para"]
查看link:../deploy/aide-requirements.html["AIDE 要求"]和link:../deploy/deployment-overview.html["了解部署模式"]，以确定是否安装 AIDE Lite 或 AIDE Enterprise。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["两个"] 部署 AI Data Engine
[role="quick-margin-para"]
从 NetApp Console 部署 link:../deploy/deploy-aide-lite.html["AIDE Lite"] 或 link:../deploy/deploy-enterprise.html["AIDE 企业版"]。设置页面将引导您选择安装位置和配置大小，并运行安装命令。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三"] 连接数据源
[role="quick-margin-para"]
link:../data-sources/connect-data-source.html["连接数据源"] 开始扫描。AI Data Engine 对您指定的存储系统中的文件系统元数据进行编目。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["四个"] 浏览您的数据
[role="quick-margin-para"]
打开 link:../investigate/understand-dashboard.html["信息板"] 以查看存储优化见解，或转至 link:../investigate/investigate-data.html["调查"] 直接搜索和筛选您的元数据。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["五"] 创建策略
[role="quick-margin-para"]
link:../policies/create-policy.html["将调查筛选器保存为策略"] 以监控一段时间内符合相同标准的文件。您可以配置策略以发送通知、永久删除匹配文件或跟踪结果。
